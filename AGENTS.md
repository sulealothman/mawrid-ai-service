## Application Building Context

Read the following files in order before implementing or making any architectural decision:

1. `context/architecture-context.md` — system structure, boundaries, data responsibilities, contracts, and invariants
2. `context/code-standards.md` — implementation rules and conventions
3. `context/testing-context.md` — test writing rules and testing scope
4. `context/ai-workflow-rules.md` — development workflow, scoping rules, and delivery approach
5. `context/progress-tracker.md` — current phase, completed work, open questions, and next steps

Update `context/progress-tracker.md` after each meaningful implementation change.

If implementation changes architecture, scope, contracts, testing rules, or standards documented in the context files, update the relevant file before continuing.
